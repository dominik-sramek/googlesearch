'Vytvoř frontend klon Google vyhledávače podle zadání CS50 Project 0.

* image.html: Vyhledávání obrázků odesílající na Google (parametry q a tbm=isch).
* advanced.html: Rozšířené vyhledávání podle CS50 s modrým tlačítkem zarovnaným doleva.
* forms.html: Stránka obsahující různé formulářové prvky jako input, select, checkbox, radio, textarea a button[cite: 1]. Všechny tyto formuláře označ jako nefunkční, například zašednutím nebo poznámkou[cite: 1].
* Společné prvky: Na všechny stránky projektu přidej odkaz na validaci HTML a CSS pro danou stránku[cite: 1]. Dále na všechny stránky přidej odkaz na soubor citace.md obsahující použité zdroje a prompty[cite: 1]. Na všechny stránky také přidej odkaz na mé portfolio na doméně dominik-sramek.github.io[cite: 1].
* styles.css: Napodob co nejvěrněji vzhled skutečného Googlu.'
